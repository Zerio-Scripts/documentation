# Installation Guide

<Callout type="warning">
  **These pages cover the old zerio-radio V2.** V3 is the current version: see
  the [V3 installation guide](/radio/installationguide) and the [migration
  guide](/radio/migrating).
</Callout>

Assuming you have all dependencies noted, there should be no specific installation steps required. You would simply add the script to your server and start it.

## Configure the resource

We do **highly** recommend to familiarize yourself with, or atleast look through, the configuration files. These files are in the `shared` folder of Zerio Radio.
